# glTF sample models

From Khronos's [glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
(`Models/<name>/glTF-Embedded` or `glTF-Binary`), all CC0-1.0 per their
`metadata.json`: Triangle, TriangleWithoutIndices, AnimatedTriangle,
SimpleSkin, SimpleMorph, AnimatedMorphCube. `test/model.test.mjs` checks
`ludo toolbox model info` against Khronos's glTF-Validator on them.
